# distances
Code and supporting files for calculating genetic distances on simulated data.

- `subsampling.sh` = script for performing clustered and random sub-sampling of simulated genetic data
- `demes.txt` = list of demes used by `subsampling.sh`
- `neighbours.tsv` = list of neighbour pairs used by `subsampling.sh`
- `samples_0gen.txt` = list of samples within demes used by `subsampling.sh`
- `samples_300gen.txt` = list of samples within demes used by `subsampling.sh`
- `distances_subsampling_mac1.sh` = script for calculating genetic distances using MAC=1 filter
- `distances_subsampling_maf01.sh` = script for calculating genetic distances using MAF=1% filter

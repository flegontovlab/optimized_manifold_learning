# simulations
Code and supporting files for our SSL simulations.

- `landscape.R` = script to generate a stepping-stone landscape (SSL) used by simulation scripts
- `landscape.csv` = the SSL metadata table with deme names, coordinates, and point colours and sizes for plotting, generated by `landscape.R`
- `neighbour_pairs.tsv` = list of neighbour pairs generated by `landscape.R`
- `helper_functions_hexagons.R` = helper functions for landscape generation
- `sim_200mb_IBD.R` = script for the isolation-by-distance (IBD) simulation
- `sim_200mb_IBR.R` = script for the isolation-by-resistance (IBR) simulation
- `sim_200mb_IBR-LDM.R` = script for the isolation-by-resistance with long-distance migrations (IBR-LDM) simulation
